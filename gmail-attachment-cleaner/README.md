# Gmail添付ファイルクリーナー

Gmailの添付ファイルだけを、本文を残したままIMAP経由で一括削除するWindows専用アプリです。

紹介記事: https://shoroji.com/2026/09/5099/

## できること

- 対象フォルダ内の添付ファイル付きメールを検索して一覧表示（添付合計サイズの大きい順）
- チェックしたメールの添付ファイルだけを削除し、添付ファイル付きの元メールは指定フォルダへ退避（未設定なら完全削除）
- 添付を削除したメールの本文先頭に「Deleted: ファイル名（サイズ）」の注記を自動挿入
- 一覧からメールをダブルクリックすると、メーラーで開いたような見た目で本文を確認できる（そこから添付削除・メール削除も実行可能）
- 「保護」列・「メール削除」列で、消したくないメールの保護／メールごと削除の対象指定が個別にできる
- 日本語・英語のUI切り替えに対応（外部の`lang_ja.ini` / `lang_en.ini`を編集すれば文言も調整可能）
- IMAP通信はすべてバックグラウンドスレッドで実行するため、処理中も画面が固まらない

## 必要なもの

- Delphi（RAD Studio 12で開発。Indy10は標準搭載）
- SSL/TLS接続する場合は `libeay32.dll` / `ssleay32.dll`（OpenSSL 32bit）をexeと同じフォルダに置く
  - 入手先の例: https://indy.fulgan.com/SSL/

## ビルド方法

1. `imap_attachment_cleaner.dproj` をDelphiで開く
2. F9でビルド・実行（または `dcc32 imap_attachment_cleaner.dpr`）
3. `lang_ja.ini` / `lang_en.ini` を、ビルドしたexeと同じフォルダに置く（言語切り替え用の外部ファイル）

## 使い方

1. 左側のパネルに接続先（IMAPサーバー・ユーザー名・パスワード等）と、対象フォルダ・移動先フォルダを入力し、「1. この内容で登録」でプロファイルとして保存できる
2. 「2. 接続」→（デフォルトで自動的に）「3. 一覧取得」
3. 添付を削除したいメールにチェックを入れ、「4. 選択した添付を削除」
4. メールごと削除したい場合は「メール削除」列にチェックを入れ、「5. 選択したメールを削除」

設定は、exeと同じフォルダの `imap_settings.ini` に保存されます（パスワードは簡易難読化。暗号化ではないため取り扱いに注意してください）。

## 動作の仕組み（重要）

IMAPプロトコルには「メールの一部分（添付ファイルだけ）を直接書き換える」命令がありません。そのためこのツールは以下の手順で実質的に同じ結果を得ています。

1. 対象メールをまるごとダウンロード
2. 添付ファイルのパートだけをメモリ上で取り除く（本文・件名・差出人などのヘッダー情報はそのまま維持）。削除した添付のファイル名を本文先頭に注記として挿入
3. 添付を除いたメールを元のフォルダに新規メールとしてAPPEND（追加登録）
4. 移動先フォルダが設定されていれば、添付ファイル付きの元メールをそのフォルダへ退避（Gmailの通常ラベルの場合はラベル操作、ゴミ箱等の特殊フォルダの場合はCOPY）。未設定なら削除フラグを立てる
5. 最後にまとめてEXPUNGE（完全削除）を実行

これはThunderbirdの「添付ファイルを削除」機能と基本的に同じ考え方です。途中でエラーが起きた場合、元メールは削除フラグが付いたまま残ることがあります（EXPUNGEされるまでは復元可能）。心配な場合は事前に該当フォルダをサーバー側でコピー/バックアップしておくことをおすすめします。

## 注意点・既知の制限

- この処理（特に移動先フォルダを空欄にした場合）は「元に戻せません」。テスト用のフォルダやコピーしたメールで一度動作確認してから、本番のメールボックスに使ってください。
- 移動先フォルダ名は、サーバーによってはASCII文字のみ対応（日本語フォルダ名はIMAPの仕様上Modified UTF-7というエンコードが必要です）。迷ったら初期値の`DeletedAttachments`のような半角英数字のフォルダ名をおすすめします。
- 添付の中身はダウンロードせず構造情報だけを見て一覧を作るため軽量ですが、「サイズの大きい順」は検索を打ち切った範囲内での並び替えです。フォルダ全体から本当に大きい添付を探したい場合は、検索件数を0（全件）にしてください。
